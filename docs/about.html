PLATFORMIO

BUILD + FLASH.

$ pio run
$ pio run -t upload
$ pio device monitor

Serial @ 115200. Set upload_port in platformio.ini or pass -upload-port COMx.

UPLOAD FAIL

Close monitor. Hold BOOT → tap EN. Still fail: unplug TFT DC from P2, flash, reconnect. Use a data USB cable.

BLANK SCREEN

Hardwire TFT LED to 3V3. Check MOSI on P23.

BROWNOUT

WiFi scan/AP current spike. Weak USB resets to main menu. Powered hub or 5V on VIN.
